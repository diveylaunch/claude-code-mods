# Changelog

## 0.1.1 (2026-11-09)

- The details line no longer cuts the model name right before the token count.
- Removed the dotted background behind the rows.

## 0.1.0 (2026-11-09)

First release of `agent-panel`.

- Panel with one row per subagent: type, model, effort, tokens, time, memory.
- The row fills as the agent works; the color follows the kind of work.
- Team progress line above the list.
- Memory from 50% and the largest token spend are highlighted.
- 21 animated stickers that follow what each agent is doing.
- English and Russian. Hebrew headings and buttons.
